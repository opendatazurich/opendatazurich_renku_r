## Checkout other datasets? Shut down session!

You want to checkout other datasets? Please **shut down this session** before, by clicking on the **trash bin icon** in the upper left corner ("shut down session").

## Save your work?

If you want to save your work for later there are several options:
- Download the `.Rmd`-File: Select the file in the files panel in the lower right corner. Then click "More" -> "Export..." to save it on your machine
- [Integrate Github/Gitlab in your Renku Account](https://docs.renkulab.io/en/latest/docs/users/code/guides/connect-renku-account-to-github-or-gitlab-account/)
- Add a github repository via the terminal tab (you need to create a Github access token with write permissions first)
